# AddOns-Ascension-Bronzebeard
AddOns I ported and/or adjusted to work on Ascension's Bronzebeard realm

Since this is mostly for myself, I don't always bother porting every little bit of functionality.
AddOns are provided as is and usually received minimal effort to achieve a bug free state. 

For anything PvP related, you most likely will have to add more Ascension spell IDs since they're all different from any retail version. I've tried to mitigate this by using spell names (localized from ID) where possible.
